# SiteDoisBlazor

Aplicação web em Blazor para demonstração de páginas interativas e componentes reutilizáveis tarefas passada em sala de Aula de Desenvolvimento Web Usabilidade, Dev. Web, Mobile e Jogos.

## Tecnologias

- .NET 10
- ASP.NET Core
- Blazor Web App
- C#

## Estrutura principal

- `Program.cs` - configuração da aplicação e registro dos serviços do Blazor
- `Components/Pages` - páginas da aplicação
- `Components/Layout` - layout e navegação
- `wwwroot` - arquivos estáticos e estilos

## Páginas disponíveis

- Home
- Counter
- Conversor
- Media
- Sorteio
- Weather

## Como executar

1. Abra o terminal na pasta do projeto
2. Execute:

```bash
dotnet restore
dotnet run
```

3. Acesse a URL exibida no terminal, normalmente:

```text
https://localhost:5001
```

ou

```text
http://localhost:5000
```

## Observações

Este projeto foi criado como uma aplicação Blazor Server com renderização interativa e navegação por componentes.
